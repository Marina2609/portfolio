# 💼 Frontend Developer Portfolio — Марина

Добро пожаловать в мой центральный репозиторий-портфолио. Здесь собраны проекты, демонстрирующие мой путь в веб-разработке: от фундаментального владения чистым JavaScript (Vanilla JS, ООП, модули) до построения сложных Single-page Applications (SPA) на **React** и **TypeScript** с интеграцией внешних REST API.

---

## 🛠️ Технологический стек & Коммерческие навыки

- **Фреймворки и Языки:** React, TypeScript, JavaScript (ES6+), Node.js.
- **Архитектура и Базы данных:** ООП (классы/прототипы), REST API.
- **Верстка и UI:** Семантическая валидная верстка, CSS3/Sass (Flexbox, Grid, 3D-transforms), Desktop First адаптив, работа с графикой в Figma.
- **Инструменты и Сборка:** Webpack 5, Git, SVN, ESLint, Prettier.
- **Методологии:** Понимание принципов Scrum/Agile (работа спринтами, код-ревью, важность предсказуемых процессов).

---

## 🗺️ Карта проектов (Навигация по веткам)

Каждый проект изолирован в своей ветке и снабжен детальной технической документацией.

### 1. 🇬🇧 RS Lang — Web Application for Learning English

- **Стек:** React, TypeScript, React Router DOM, REST API, `react-paginate`, `react-countdown-circle-timer`.
- **Что демонстрирует:** Умение работать в масштабной архитектуре со строгой типизацией (TypeScript Strict Mode), авторизацией пользователей, постраничной пагинацией данных и долгосрочной аналитикой статистики.

### 2. 🎵 Audio Quiz — Музыкальное SPA-приложение

- **Стек:** Vanilla JS (Классы, ООП), Webpack 5, Web Audio API, HTML5 Canvas, CSS 3D-transforms.
- **Что демонстрирует:** Написание сложного клиентского приложения без фреймворков. Чистая ООП-архитектура, динамический рендеринг HTML через JS, работа со звуковым движком и сборка проекта с нуля на Webpack 5.
- **🔗 Живое демо:** [audio-quiz-mg.netlify.app](https://audio-quiz-mg.netlify.app)

### 3. 🏛️ Museum — Welcome to the Louvre

- **Стек:** JavaScript (ES6+), HTML5/CSS3 (Медиа-запросы, кастомные сетки), Mapbox API.
- **Что демонстрирует:** Идеальная семантическая верстка по Figma, кастомный HTML5 видеоплеер с индивидуальными контроллерами, бесконечные слайдеры, интерактивный калькулятор стоимости билетов с валидацией форм и интеграция кастомных карт Mapbox.
- **🔗 Живое демо:** [museum-mg.netlify.app](https://museum-mg.netlify.app)

### 4. 🌅 Momentum — Dashboard Application

- **Стек:** JavaScript Modules (ES-модули), Fetch API (`async/await`), Unsplash/Flickr API, OpenWeatherMap API, LocalStorage.
- **Что демонстрирует:** Асинхронное взаимодействие с внешними REST API, декомпозиция JS-кода на модули, работа с состоянием и сохранением пользовательских настроек в LocalStorage, использование рекурсивных таймеров.
- **🔗 Живое демо:** [momentum-mg.netlify.app](https://momentum-mg.netlify.app)

### 5. ↕️ Vertical Slider — Интерфейсный компонент

- **Стек:** JavaScript (Vanilla JS), CSS Transitions, Absolute Positioning, CSS Transform.
- **Что демонстрирует:** Управление DOM-деревом, расчет высоты вьюпорта «на лету» и реализация высокопроизводительной, плавной интерфейсной анимации (60 FPS) со встречным движением контента.
- **🔗 Живое демо:** [vertical-slider-mg.netlify.app](https://vertical-slider-mg.netlify.app)

### 6. 📊 Presentation — Inside React

- **Стек:** Reveal.js, HTML5/CSS3, Markdown, Технический английский язык.
- **Что демонстрирует:** Глубокое понимание теории: жизненный цикл компонентов React, Props/State, асинхронность `setState` (batching) и работа с Refs. Написана полностью на английском языке.
- **🔗 Живое демо:** [reveal-presentation-react.netlify.app](https://reveal-presentation-react.netlify.app)

## 🚀 Как запустить любой проект локально

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Marina2609
   cd portfolio
   ```
2. Переключитесь на интересующую вас ветку проекта:
   ```bash
   git checkout [имя_ветки]
   ```
3. Следуйте индивидуальной инструкции в файле `README.md` внутри выбранной ветки для установки зависимостей (`npm install`) и запуска.
