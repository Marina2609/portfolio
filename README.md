# ↕️ Vertical Slider — Путешествовать, Мечтать, Любить, Дружить

Интерактивный вертикальный слайдер с синхронизированной анимацией текста и фоновых изображений, реализованный на чистом JavaScript (Vanilla JS). Проект демонстрирует навыки работы с манипуляцией DOM-деревом, кастомными анимациями и управлением позиционированием элементов.

## 🛠️ Стек технологий и инструменты

- **Frontend Core:** JavaScript (ES6+), HTML5, CSS3
- **Позиционирование:** CSS Flexbox, Absolute Positioning
- **Анимации:** CSS Transitions, Transform (`translateY`)
- **Деплой:** Netlify

---

## 💡 Реализованный функционал и технические особенности

- **Синхронизированный скролл:** При клике на кнопки навигации (Вверх/Вниз) левая текстовая панель и правая панель с изображениями двигаются в противоположных направлениях, создавая бесшовный эффект смены экранов.
- **Динамический расчет высоты:** Логика JavaScript автоматически высчитывает высоту слайдера на основе размеров окна просмотра (`viewport height`), что обеспечивает корректное отображение на любых разрешениях.
- **Плавные переходы:** Плавность переключения кадров реализована средствами CSS-свойств `transition` и `transform`, что гарантирует высокую производительность (60 FPS) без просадки кадров.
- **Адаптивность:** Слайдер адаптирован под различные размеры экранов для сохранения читаемости текста и центрирования фоновых изображений.

## 🚀 Как запустить проект локально

1. Клонируйте репозиторий и перейдите в ветку проекта:

   ```bash
   git clone https://github.com
   cd portfolio
   git checkout vertical-slider
   ```

2. Запустите проект:
   Проект написан на чистом стеке и не требует сборки. Достаточно открыть файл `index.html` напрямую в браузере или использовать плагин _Live Server_ в вашей IDE.
