# 🌅 Momentum Dashboard Application

Функциональный персональный дашборд — аналог одноименного расширения для браузера Chrome. Приложение динамически адаптирует интерфейс под время суток, агрегирует данные из внешних источников по API и предоставляет пользователю удобные встроенные виджеты для продуктивности.

## 🛠️ Стек технологий и инструменты

- **Frontend Core:** JavaScript (ES6+), HTML5, CSS3
- **Data Fetching:** Асинхронные запросы (Fetch API / `async/await`)
- **Интеграция сторонних API:** Unsplash API, Flickr API, OpenWeatherMap API
- **Хранение данных:** Браузерное LocalStorage API
- **Деплой:** Netlify

---

## 💡 Реализованный функционал и ключевые навыки

- **Архитектура и чистый код:** Архитектура проекта построена на делении JavaScript-кода на изолированные модули, что обеспечивает легкость поддержки и масштабирования.
- **Динамический интерфейс:** Реализована работа с датой и временем. Приложение автоматически рассчитывает текущее время суток, на основе чего динамически меняет приветствие пользователя и фоновые изображения.
- **Продвинутый слайдер:** Разработан слайдер фоновых изображений. Поддерживается как загрузка стандартных локальных ассетов, так и динамическое получение обоев высокого разрешения из внешних источников через **Unsplash API** и **Flickr API**.
- **Асинхронные виджеты:** Внедрен виджет погоды, обновляющий данные в реальном времени на основе выбранного населенного пункта. Добавлен блок «Цитата дня», подтягивающий случайные цитаты через стороннее API.
- **Аудиоплеер:** Создан встроенный аудиоплеер с поддержкой кастомных плейлистов, трек-бара и возможностью циклического/последовательного воспроизведения аудиофайлов.
- **Сохранение состояния (Persistence):** Настройки приложения, имя пользователя и его населенный пункт надежно сохраняются в **LocalStorage**, что позволяет сохранять персонализацию даже после полной перезагрузки страницы.
- **Оптимизация таймеров:** Для точного обновления часов и элементов интерфейса используется оптимизированный подход с **рекурсивным `setTimeout`**, предотвращающий просадку производительности.

## 🚀 Как запустить проект локально

1. Клонируйте репозиторий и перейдите в ветку проекта:

   ```bash
   git clone https://github.com/Marina2609
   cd portfolio
   git checkout momentum
   ```

2. Запустите проект:
   Проект написан на чистом модульном JS и готов к работе. Запустите его через локальный сервер (например, расширение _Live Server_ в VS Code), чтобы браузер корректно обрабатывал локальные JS-импорты (`type="module"`).
