# 🏛️ Museum — Welcome to the Louvre

Интерактивное веб-приложение (SPA/Landing) для виртуального знакомства с музеем Лувра. Проект объединяет продвинутые техники современной адаптивной верстки, кастомные элементы мультимедиа и сложную интерактивную логику, реализованную на чистом JavaScript.

---

## 🛠️ Ключевые навыки и технологии

### 📐 Верстка и Архитектура интерфейса

- **Семантика и валидность:** Чистый, валидный HTML5-код, написанный с учетом стандартов доступности и SEO.
- **Построение сеток:** Сложные интерфейсные сетки, реализованные с применением современных спецификаций **Flexbox** и **CSS Grid Layout**, а также динамических функций `calc()` и CSS-переменных.
- **UI-компоненты:** Стилизация и адаптивная верстка навигационных панелей, карточных элементов интерфейса, форм ввода и интерактивных элементов управления (кнопки, ссылки, переключатели).
- **Графика и дизайн:** Профессиональный экспорт стилей и графических ассетов из **Figma**. Корректная интеграция и оптимизация растровых (PNG, JPEG, WebP) и векторных (SVG) изображений.
- **Типографика:** Подключение и оптимизация кастомных шрифтов.

### 🎨 CSS-Анимации и Эффекты

- Реализация эффекта **параллакса** для глубокого визуального погружения.
- Нативная плавная прокрутка страницы по якорным ссылкам.
- Интерактивные микро-взаимодействия: изменение стилей, состояний элементов при наведении (`:hover`), фокусе (`:focus`) и клике (`:active`).

### 📱 Адаптивность и Рефакторинг

- Применение методологии **Desktop First** для поэтапного масштабирования интерфейса с помощью `media queries`.
- Гарантия кроссбраузерности и корректного отображения верстки на большинстве современных устройств (от смартфонов до UltraWide-мониторов).
- Проведение регулярного рефакторинга кода для устранения дублирования стилей и повышения читаемости.

### ⚡ JavaScript Интерактив (JS Core)

- **Мультимедиа:** Разработка кастомного **HTML5 видеоплеера** с индивидуальным дизайном панели управления (кастомные контроллеры громкости, воспроизведения и прогресс-бара).
- **Слайдеры:** Написание алгоритма **бесконечного слайдера/свайпера** для демонстрации экспонатов, а также внедрение специализированного слайдера сравнения изображений («до/после»).
- **Анимации:** Реализация динамической анимации элементов в секции _Gallery_ при прокрутке страницы (Scroll Animations).
- **Бизнес-логика:** Разработка интерактивного **калькулятора продажи билетов** в секции _Tickets_ и внутри модальной формы заказа (автоматический расчет стоимости, валидация типов билетов).
- **Валидация:** Проверка вводимых пользователем данных в формах на стороне клиента перед отправкой.
- **Геолокация и Карты:** Интеграция и тонкая кастомизация интерактивной карты с помощью JS-библиотеки **Mapbox** (изменение стилей карты, добавление и кастомизация уникальных маркеров).

## 📂 Структура проекта

- `index.html` — главная точка входа.
- `assets/css/` — архитектура стилей (переменные, сетки, медиа-запросы).
- `assets/js/` — модульная логика приложения (плеер, калькулятор, слайдеры, карта).
- `assets/video/` & `assets/images/` — медиа-ресурсы проекта.

## 🚀 Как запустить проект локально

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com
   cd portfolio
   ```
2. Переключитесь на ветку проекта:
   ```bash
   git checkout museum
   ```
3. Проект не требует сложной сборки и готов к запуску. Вы можете открыть файл `index.html` напрямую в браузере или запустить через локальный сервер (например, расширение _Live Server_ в VS Code).
