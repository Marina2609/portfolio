# 🎵 Audio Quiz — Адаптивное музыкальное SPA-приложение

Интерактивное Single-page Application (SPA) игрового типа, созданное для проверки и улучшения музыкальной эрудиции. Проект демонстрирует продвинутый уровень владения чистым JavaScript, архитектурными паттернами проектирования (ООП), модульной сборкой и глубокой интеграцией Web Audio API.

## 🛠️ Стек технологий и инструменты

- **Frontend Core:** JavaScript (ES6+), HTML5, CSS3 (включая сложные 3D-трансформации)
- **Архитектура:** Объектно-ориентированное программирование (классы, прототипы, инкапсуляция логики)
- **Мультимедиа и графика:** HTML5 Audio API, HTML5 Canvas (для визуальных эффектов)
- **Сборщик проекта:** Webpack 5 (настройка минификации, оптимизации ассетов, лоадеров)
- **Хранение данных:** LocalStorage API
- **Деплой:** Netlify

---

## 💡 Реализованный функционал и архитектурные особенности

- **Продвинутая ООП-архитектура:** Приложение полностью спроектировано на чистом JavaScript с использованием классов и прототипов. Логика игры, подсчет очков и управление состояниями инкапсулированы в изолированные сущности.
- **Динамический рендеринг:** Генерация HTML-структур и UI-элементов страниц реализована динамически «на лету» через JavaScript, что обеспечивает мгновенную реакцию интерфейса без перезагрузки страниц (SPA).
- **Игровые режимы:** Разработаны три независимых тематических модуля:
  - Интерактивный звуковой квиз с аудио-угадыванием треков.
  - Визуальное распознавание композиторов.
  - Текстовый модуль для проверки теории музыки.
- **Бесконечный режим «Музыкальный блиц»:** Высокоинтенсивный игровой режим, включающий умный алгоритм динамической работы над ошибками игрока и специальную финальную фазу «Супер-игры».
- **Мультимедиа и Canvas:** Интеграция HTML5 Audio для бесшовного воспроизведения и микширования звуковых эффектов. Использование Canvas для реализации отзывчивой визуализации игрового процесса.
- **Сохранение прогресса:** Игровая статистика, рекорды, история прохождения режимов и настройки пользователя кэшируются и сохраняются между сессиями с помощью **LocalStorage**.
- **3D-графика средствами CSS:** Интерфейс включает сложные, современные **3D-трансформации** элементов UI (например, анимации переворота карточек, объемные переходы между экранами), построенные на Flexbox и CSS Grid.

## 🚀 Как запустить проект локально

1. Клонируйте репозиторий и перейдите в ветку проекта:

   ```bash
   git clone https://github.com/Marina2609
   cd portfolio
   git checkout audio_quiz
   ```

2. Установите зависимости и запустите локальный сервер разработки:

   ```bash
   npm install
   npm run start
   ```

3. Для сборки оптимизированного продакшн-бандла:
   ```bash
   npm run build
   ```
