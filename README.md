# 📊 Reveal.js Presentation — Inside React

Интерактивная адаптивная веб-презентация, созданная с использованием фреймворка **Reveal.js**. Проект разработан как учебное и демонстрационное пособие, подробно объясняющее внутреннее устройство, архитектуру и ключевые концепции библиотеки React.

## 🛠️ Стек технологий и инструменты

- **Core Framework:** Reveal.js (для создания слайдовых презентаций средствами HTML/JS)
- **Frontend Core:** JavaScript (ES6+), HTML5, CSS3 / Стилизация слайдов
- **Тематика контента:** React.js Core Concepts (Компоненты, State, Props, Refs, Lifecycle)
- **Деплой:** Netlify

---

## 💡 Содержание презентации и технические концепции

Проект визуализирует и детально разбирает следующие фундаментальные темы экосистемы React:

- **Архитектура компонентов:** Разделение интерфейса на независимые переиспользуемые блоки. Сравнение функциональных компонентов (`Functional Components`) и классовых компонентов (`Class Components`), включая работу метода `render()`.
- **JSX (JavaScript XML):** Синтаксис расширения JavaScript, особенности интеграции JS-переменных и выражений внутрь разметки.
- **Управление состоянием (State):** Хранение локальных данных компонента, реактивное обновление пользовательского интерфейса на основе событий и вызова функций.
- **Асинхронность `setState`:** Разбор механизма пакетного обновления состояния (batching) и правильный подход к изменению текущего состояния на основе предыдущего (`updater function`).
- **Передача данных (Props):** Механизм коммуникации между родительскими и дочерними компонентами, передача данных и функций обратного вызова (event handlers) через свойства.
- **Работа с DOM-деревом (Refs):** Использование атрибута `ref` для получения прямого доступа к HTML5-элементам (например, к тегу `<audio>` для управления воспроизведением звука).

## 🚀 Как запустить проект локально

1. Клонируйте репозиторий и перейдите в ветку проекта:

   ```bash
   git clone https://github.com/Marina2609
   cd portfolio
   git checkout react-presentation
   ```

2. Запустите проект:
   Проект не требует сложной серверной сборки. Достаточно открыть файл `index.html` напрямую в браузере или использовать расширение _Live Server_ в VS Code для корректной навигации по слайдам.
